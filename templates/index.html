AWS Connection Setup

This dashboard queries real Amazon S3 buckets using boto3 without exposing credentials in code.

Option 1: Project .env file (Recommended)

Create a file named .env in the project root based on .env.example:

AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=wJalr...
SOURCE_BUCKET_NAME=compliance-source-rahul-2026
SOURCE_BUCKET_REGION=ap-south-1
DEST_BUCKET_NAME=compliance-destination-rahul-2026
DEST_BUCKET_REGION=ap-southeast-1

Option 2: AWS CLI Credentials

Run aws configure in your terminal to set your default credentials in ~/.aws/credentials.

Required IAM Permissions

The IAM user/role should have read access to both buckets:

  • s3:ListBucket, s3:GetObject
  • s3:GetBucketVersioning, s3:GetBucketReplication
  • s3:GetBucketPublicAccessBlock, s3:GetEncryptionConfiguration
